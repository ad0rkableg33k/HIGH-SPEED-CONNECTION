What it does

Built for active communities

📷
CAMERA ON POLICY

No more awkward VC confrontations with people who won't turn their cam on. Enable this feature and it will mention the user in violation and give them a grace period to turn their cam on. If they do not turn it on they will be removed from the VC. Fully configurable timing, mmonitored channels & exempt roles.

📋
CHANNEL INDEXER

CHANNEL INDEXER : Exports every channel + custom descriptions to JSON and posts a formatted, clickable index embed.

💨
SPEED MATCH // Clouds N Chill

Automated Speed Match event that pairs members up to hang, talk, and vibe together. Timed rounds, no-repeat pairing logic, staff control panel. 1-on-1, 2v2, or 3v3. Also a stand-alone server that hosts events for multiple servers or you can add the category and channels to your own.

Commands

Slash command reference

/channel-index Posts a categorized embed with clickable links to every channel. Filter by category with category:Name.
/export-channels Sends you channels.json directly in Discord. Ephemeral — only you see it.
/userinfo Profile info for any user. Works even if they've left the server — pass their raw user ID.
/camera-policy Toggle camera enforcement on or off. No restart needed. Requires Manage Server.
/camera-monitor Add, remove, or list monitored voice channels.
/camera-exempt-role Manage roles that skip camera enforcement entirely.
/camera-timing Set grace and warning period lengths. Default: 2 min silent + 3 min warning.
/camera-announcement Attach a policy announcement URL to reminder messages.
/speed-match SPEED MATCH // Clouds N Chill event control — configure and run pairing rounds.

Get started

Up in five minutes

01

Add the bot to your server

Use the invite link above. Make sure the bot role sits above the roles it needs to manage in your server's hierarchy.

02

Configure via slash commands

No config files to edit. Set up camera policy and event settings entirely through Discord slash commands.

03

Enable privileged intents (camera features)

Discord Developer Portal → your bot → Bot page → Privileged Gateway Intents → enable Server Members Intent. Required for camera enforcement and voice channel management.

04

Self-hosting? Grab the source

Node.js + npm install + a .env with your bot token and guild ID. Fly.io-compatible with persistent volume support. Full instructions in the README. Running an event? Check the Speed Match Setup Guide.
